# EFIP1-DistribuidoraMaestro
Sistema de Gestión de Pedidos para Distribuidora Maestro es un aplicativo desarrollado en Java, diseñado específicamente para facilitar la creación, modificación, eliminación y visualización de pedidos en la empresa Distribuidora Maestro SRL, que se especializa en la distribución mayorista y minorista de productos de ferretería. Además, permite gestionar de manera eficiente tanto a los clientes como los productos asociados a cada pedido.

El sistema implementa una arquitectura moderna basada en el patrón Modelo-Vista-Controlador (MVC) y el uso de Data Access Object (DAO) para garantizar una estructura modular, escalable y fácilmente mantenible, permitiendo futuras expansiones del sistema y asegurando la adaptabilidad a los cambios en el negocio.

Este proyecto tiene como objetivo mejorar los procesos internos de gestión de pedidos, reducir errores operativos y optimizar la relación con los clientes.
Propuesta Funcional
Para optimizar la administración de pedidos y mejorar la eficiencia operativa en Distribuidora Maestro SRL, se propone el desarrollo de un sistema integral de gestión de pedidos. Este sistema permitirá gestionar el ciclo completo de los pedidos, desde su creación hasta su cierre, mejorando la precisión, la velocidad de procesamiento y la satisfacción del cliente. Además, integrará funcionalidades que asegurarán un mejor control del inventario y una interacción fluida entre los distintos actores involucrados en el proceso.


# Sistema de Gestión para Distribuidora Maestro

Este proyecto consiste en el desarrollo de un sistema de gestión para la empresa Distribuidora Maestro SRL, especializada en la venta mayorista y minorista de productos de ferretería.

## Características
Características principales del sistema:
1.	Gestión de Pedidos:
o	Creación y modificación de pedidos: Los usuarios podrán crear y modificar pedidos de forma intuitiva y eficiente, optimizando el registro de productos y su correcta transcripción.
o	Visualización y seguimiento de pedidos: El sistema permitirá consultar el estado de cada pedido, facilitando la visualización de los detalles de cada uno, como productos solicitados, cantidades y fechas de entrega.
o	Eliminación de pedidos: Solo los administradores podrán eliminar pedidos que hayan sido finalizados.
2.	Gestión de Inventarios:
o	Actualización automática del stock: Los pedidos procesados actualizarán automáticamente la disponibilidad de productos en tiempo real.
o	Control de productos faltantes: El sistema alertará sobre productos agotados y evitará la inclusión de artículos no disponibles en los pedidos.
3.	Módulo de Reportes y Estadísticas:
o	Generación de informes: El sistema permitirá generar reportes detallados sobre los pedidos realizados, el stock actual, productos más solicitados y la eficiencia del proceso.
o	Mejora de procesos: A partir de la información recabada, será posible optimizar el proceso de pedidos y mejorar la atención al cliente.
